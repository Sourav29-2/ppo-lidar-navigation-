ROOT CAUSE CONCLUSION
======================================================================

  Primary geometric cause  : NARROW_PASSAGE (14/24 = 58.3%)
  Secondary cause          : SPEED_DURING_TURN (4/24 = 16.7%)

  ── Velocity-control failures (LATE_REACTION + SPEED_DURING_TURN) : 7/24 (29.2%)
  ── Pure geometry failures (NARROW + BAD_START + TURNING)         : 14/24 (58.3%)
  ── Nav2 path failures (UNSAFE_NAV2_PATH)                         : 2/24 (8.3%)

  CONCLUSION:
  The dominant collision mechanism is VELOCITY-RELATED PPO local control.
  The robot approaches obstacles at speed (max_vel > 0.28 m/s) and either:
    a) Does not decelerate in time (LATE_REACTION), or
    b) Maintains speed while curving toward tight geometry (SPEED_DURING_TURN).

  The fix: penalise linear_vel > 0.20 m/s when any LiDAR sector < 0.45 m.
  This is a PPO reward-shaping problem, NOT a Nav2 path geometry problem.
